Before You Start
  • Open YouTube Studio (studio.youtube.com)
  • Set your Channel Language in Settings — the extension uses it as the base to duplicate from
  • Apply channel-wide settings like "Not made for kids" to all your videos — the plugin can handle this automatically during the automation run (toggle in Settings)
How It Works

The extension automates the multi-click workflow inside YouTube Studio. It opens the subtitle editor, selects your target language, and publishes — all without you touching the page. For bulk runs it repeats this for every video in the current tab (Videos, Shorts, or Live).

Be Patient

Each step waits for YouTube Studio's interface to fully load before proceeding. Some steps can take up to 10 seconds, and a single video can take up to ~30 seconds to complete. This is normal — do not navigate away while it runs.

In bulk mode an additional 30–60 second delay is added between videos (configurable in Settings) to avoid overloading YouTube's servers.

Limits & Tips
  • Videos with no existing subtitles are skipped automatically — there is nothing to translate from
  • Processed videos are cached — re-runs are fast. Use Clear Skip Cache in Settings to reprocess them
  • Run the bulk process separately for the Videos, Shorts, and Live tabs
  • Test on a single video first before launching a bulk run
  • For videos longer than ~30 minutes, enable Long video mode in Settings — it gives YouTube up to 5 minutes to finish translating large subtitle tracks instead of the default 60 seconds
